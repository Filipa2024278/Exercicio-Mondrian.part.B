# Processo de trabalho - Parte B

Na Parte B, decidi acrescentar movimento à composição, mantendo a estrutura original do quadro. Depois de ter reproduzido as formas geométricas e as cores, experimentei utilizar o código para criar uma pequena animação. Optei por fazer o retângulo azul piscar, alternando entre aparecer e desaparecer, enquanto o resto da composição permanece estático. Para isso, explorei a forma como o p5.js permite alterar as cores e controlar o tempo através do código. Fui ajustando a velocidade da animação até encontrar um ritmo que funcionasse visualmente, sem tornar o movimento demasiado rápido. Com esta alteração, procurei introduzir um elemento de dinamismo numa obra originalmente estática, mantendo a simplicidade visual e respeitando a composição de Mondrian.
